# sveltekit

A practical **SvelteKit** starter (Svelte 5 + Vite + TypeScript + Vitest).

## What's included

- `+page.svelte` with a `$state` counter demo
- `+layout.svelte` / `+layout.ts` data wiring
- Vitest smoke test
- Strict TypeScript, `adapter-auto`

## What it is NOT

- Not styled (add Tailwind or your own CSS).
- Not a backend (add server routes or a DB as needed).

## Prerequisites

- Node 20+

## Run it

```bash
npm install
npm run dev
```

## Test / build

```bash
npm run test
npm run build
```
