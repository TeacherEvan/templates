# Contributing

Thanks for contributing!

## Getting started

1. Fork and clone the repo.
2. Create a feature branch: `git checkout -b feat/short-description`.
3. Make your change with tests where applicable.
4. Run the relevant checks (lint, test, build) and ensure they pass.
5. Open a pull request with a clear description.

## Commit style

Use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add dark mode toggle
fix: correct off-by-one in pagination
docs: clarify install steps
```

## Code of Conduct

This project adheres to the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to uphold it.
