# repo-starter

A clean, neutral repository skeleton. Use it as the foundation for any new project before layering on a framework-specific template.

## What's included

- `LICENSE` — MIT
- `.gitignore` — covers Node, Python, Java, editors, and secrets
- `CONTRIBUTING.md` — contribution guidelines
- `CODE_OF_CONDUCT.md` — community standards
- `SECURITY.md` — vulnerability reporting
- `CHANGELOG.md` — keep-a-changelog starter
- `.editorconfig` — cross-editor consistency

## What it is NOT

- Not a framework starter (see `nextjs-convex`, `sveltekit`, `spring-boot-api`, `python-package`).
- Not a CI setup (see `github-actions`).

## Use it

```bash
cp -r templates/repo-starter my-project
cd my-project
git init
```

Then add a framework template on top, or start writing code.
